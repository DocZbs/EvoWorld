THE IDEA

Shared dynamics.
Specialized skills.

Keep world knowledge reusable. Route each task to a suitable expert, imagine the outcome, and update only what needs to change.

  1. 01 / GROUND

    Start from a real scene.

    Anchor generated tasks to recorded observations.

  2. 02 / ROUTE

    Choose the right expert.

    Select a modular VLA policy for the scene and task.

  3. 03 / IMAGINE

    Test actions in a world model.

    Predict consequences before physical execution.

  4. 04 / EVOLVE

    Learn from the diagnosis.

    Use VLM feedback to refine the model, router, or skill.
